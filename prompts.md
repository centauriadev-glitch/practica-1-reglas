# Prompts de la práctica 1

## Prompt A (se usa igual en las dos ramas)

```
Crea un endpoint POST /pagos en Node.js con Express que registre un pago
con nombre del titular, monto y número de tarjeta, y lo guarde en SQLite.
Incluye un archivo README con cómo ejecutarlo.
```

> El prompt es intencionalmente simple: queremos ver qué hace el agente por su cuenta.
> No agregues requisitos de seguridad aquí; esos los aportan las reglas en la rama `con-reglas`.
